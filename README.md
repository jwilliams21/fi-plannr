# Fi-PlannR 📈

A modern, privacy-first financial independence and early retirement (FIRE) planning calculator. **Fi-PlannR** helps users model compound growth, simulate retirement timelines, and map out their path to financial freedom with interactive scenario testing.

---

## 🚀 Live Demo

[Explore the Live App](https://fi-plannr.netlify.app/)

---

## ✨ Features

- **Compound Interest Engine:** Real-time projection modeling based on contributions, return rates, and time horizons.
- **FIRE Calculator:** Simulates financial independence timelines with standard assumptions (3% annual expense inflation and a 4% Safe Withdrawal Rate).
- **Interactive Data Visualizations:** Dynamic charts illustrating net worth trajectories and compounding curves over time.
- **Privacy-First Architecture:** 100% client-side computation. No user data, financial inputs, or personal information are ever saved, stored, or transmitted to a backend.
- **Fully Responsive UI:** Built with clean, accessible components that adapt smoothly from mobile devices to desktop screens.
